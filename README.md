# Unidad-2-Ejercicio-10
Programacion 3 Unidad 2 Ejercicio 10
Ejercicio 10 — Diseño libre: aplicación interactiva
Al igual que en la Unidad 1, el último ejercicio es de diseño libre. Esta vez el desafío es mayor: no solo debés construir una interfaz visualmente organizada, sino que también debe ser completamente interactiva.

Pensá en una aplicación pequeña pero funcional que te resulte interesante. Puede ser una calculadora, un conversor de unidades, un formulario de reservas, un juego de preguntas y respuestas simple, o cualquier otra idea propia.

Tu aplicación debe cumplir con los siguientes requisitos mínimos:

Utilizar al menos dos layouts diferentes combinados mediante paneles anidados
Implementar al menos tres eventos distintos que produzcan cambios visibles en la interfaz
Al menos un evento debe ser de tipo ActionListener
Al menos un evento debe usar KeyListener o MouseListener
Los listeners deben estar escritos usando expresiones lambda siempre que sea posible
Al menos un componente debe cambiar su estado (texto, color, habilitado/deshabilitado) como respuesta a una acción del usuario
Junto con el código, escribí un breve párrafo explicando qué aplicación construiste, qué eventos implementaste y qué decisiones tomaste respecto a los layouts elegidos.

💡 Este ejercicio no tiene una solución única correcta. Se evaluará la coherencia entre la idea elegida, la correcta implementación de layouts y eventos, y la calidad de la interacción con el usuario.
